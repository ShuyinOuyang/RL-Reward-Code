# Training data

Training uses the AceCode dataset from TIGER-Lab, split into easy, medium and hard problems. The full splits are not included in this repository. Only a small sample is provided for testing.

* Dataset: https://huggingface.co/datasets/TIGER-Lab/AceCode-87K (formerly AceCode-89K; the old ID still redirects)
* Project page and paper: https://github.com/TIGER-AI-Lab/AceCoder

## Example data (for testing)

`example.jsonl` holds 32 problems from the hard split. Use it to check that your installation and E2B setup work before downloading the full data:

```bash
cd ar_rl         # or diffusion_rl
bash train.sh qwen2.5-coder-7b example semantic --max_steps 2
```

## Getting the full data

`process_data.py` downloads AceCode-87K from the Hugging Face Hub and selects problems by difficulty. Difficulty is the mean test pass rate of the reference completions from the models listed in the script (`qwen_coder_2.5` and `llama3_instruct`; the current release of the dataset only contains `qwen_coder_2.5` of these two, so in practice its pass rates decide the split):

* **easy**: the 25% of problems with the highest mean pass rate
* **medium**: the middle 50%
* **hard**: the 20% with the lowest mean pass rate, then filtered by the spread of pass rates across models

Run it from this folder, once per split. Save the output under these filenames, because `train.sh` looks for them:

```bash
pip install datasets fire numpy
cd data
for d in easy medium hard; do
  python process_data.py --dataset_path TIGER-Lab/AceCode-87K --difficulty $d \
      --output_path acecode_${d}_with_inference_all_1.jsonl
done
```

To train on any other file, pass it with `DATA_FILE`:

```bash
DATA_FILE=/path/to/my_split.jsonl bash train.sh qwen2.5-coder-7b hard semantic
```

## Format

One JSON object per line:

| field | used by |
|---|---|
| `question` | the prompt (`dataset_prompt_column: question`) |
| `test_cases` | list of `assert` statements, executed in E2B by `code_semantic_reward` |
| `inferences` | reference completions with their `pass_rate`, used by `code_similarity_checking_reward` |
| `id`, `source`, `context_messages` | metadata |
